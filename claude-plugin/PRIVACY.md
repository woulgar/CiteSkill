# CiteSkill plugin privacy policy

CiteSkill runs a bundled command-line tool on the user's machine. It reads the
current Git repository to validate commit references and citation trailers. When
asked to add citations, it writes `.citeskill/citations.json` and can update a
marked section of `README.md`. These files may contain names, project links, and
other information the user chooses to provide. They stay in the local repository
unless the user commits, pushes, or shares them using other tools.

CiteSkill does not collect telemetry, read credentials, send citation records to a
CiteSkill service, or retain data on a CiteSkill server. It does not upload prompts,
conversation transcripts, or tool outputs. It invokes local Git commands to check
references and trailers; it does not commit or push on its own.

The README section generated by CiteSkill includes a badge hosted by Shields.io.
When someone views a rendered README, their browser or GitHub may request that
image from Shields.io under Shields.io's own privacy practices. The badge URL
does not include citation records or repository content.

Removing CiteSkill's local records requires removing the citation manifest and
generated README section from the repository. Copies already committed or shared
through Git must be managed through that host or Git history.

For privacy questions, open an issue at
https://github.com/woulgar/CiteSkill/issues.
