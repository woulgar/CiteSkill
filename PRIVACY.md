# CiteSkill Privacy Policy

Effective September 25, 2026.

CiteSkill is an open-source command-line tool and plugin workflow maintained by Volkan Kırdar. The CiteSkill CLI runs on your computer. It does not operate a hosted service, create accounts, send telemetry, or transmit your repository data to CiteSkill's maintainer.

The CLI reads `.citeskill/citations.json` and local Git history to validate and render citations. It writes the manifest and, when requested, a README section in your repository. These files may become visible to others when you commit, push, or publish them. Citation entries can include source names, provider names, commit or PR references, and HTTPS links that you choose to provide. Do not enter private prompts, transcripts, secrets, or links you do not want to publish.

Codex, ChatGPT, Claude Code, GitHub, and other hosts or services you use with CiteSkill have their own data practices. CiteSkill does not control those services. A rendered badge may request an image from `img.shields.io` when a Markdown viewer displays it; the viewer's network request is governed by that service's practices.

For privacy questions or deletion of information in this project's own GitHub repository, open an issue at [CiteSkill issues](https://github.com/woulgar/CiteSkill/issues). For citations in someone else's repository, contact that repository's owner.
